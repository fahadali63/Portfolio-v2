# Archived designs

Earlier versions of the site, kept for reference. Nothing here is built or published: the site is built only
from `src/` and `content/` at the top of the repository, and `tsconfig.json` excludes this folder.

| Folder | Design | Replaced |
|---|---|---|
| `v6-drawing-sheet/` | Planner's drawing set: a 12-column ruled sheet, IBM Plex, paper and ink, sheet codes (G-01, P-02, B-03) | Nov 2026, by the brand-kit design ("The Shortcut") |

To look at an archived version, copy its `src/` (and `content-data/pages.ts` into `content/data/`) over the current
ones on a separate branch and run `npm run dev`.
